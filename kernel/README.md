# kernel — 私有爆款内核

离线蒸馏对标爆款得到的「判断中枢」知识资产。这是内容工厂的产品壁垒 / 信息差，
不靠堆生成模型、靠这套私有 rubric 把小白产物从 0 分拉到 70 分（见
`douyin-content-factory-goal`）。鬼谷子（选题）/ 柳永（编剧 + 质检）的内核知识都源于此。

## 真源关系

- **本目录 = 已固化的文本快照**（版本化、防丢）。
- 运行时工作副本在 gitignored 的 `state/benchmark/`，那里还混着 `.mp4` / `.paraformer.json`
  等大产物（不进 git）。
