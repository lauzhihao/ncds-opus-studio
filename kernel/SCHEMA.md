# 抖音知识口播 · 爆款拆解 Schema v1

> 用途:对标账号的每条高赞作品都按本表拆解,落库(可进 lark-base)后聚合归纳出"母规律"。
> 这是"离线蒸馏"的第一步——结构化抽取(Structured Extraction)。
> 字段按"对完播 + 涨粉的影响力"从高到低排列。

## 拆解字段

### A. 元信息
- aweme_id / 账号 / 原链接
- 时长(s) / 字数 / 语速(字/s)
- 互动数据:点赞 / 评论 / 收藏 / 转发(能采则采,用于回归"哪些维度真和爆相关")

### B. 钩子(前 3 秒) ★最高权重
- 钩子原文(逐字)
- 钩子类型:让步式 / 反常识 / 信息缺口 / 数字清单 / 身份点名 / 恐惧诉求 / 提问
- 公式拆解(由哪几个动作组成)

### C. 痛点绑定(3-15 秒)
- 怎么让目标人群"说的就是我"
- 描述的是"体感"还是"道理"(体感 > 道理)

### D. 价值预告 ★长视频防划走开关
- 有没有?在第几秒?
- 承诺了什么收益

### E. 内容骨架
- 结构类型:总分 / 递进 / 清单 / 故事 / 对比
- 分点数 & 每点是否"可执行"(可执行 = 有用感 = 收藏转发)
- 解法是"要你改变"还是"要你微调"(微调式留人更强)

### F. 可信度装置
- 权威背书:俗语/集体记忆 / 专家 / 数据 / 机制解释 / 对比锚点
- 具体化:有没有可照做的数字、步骤

### G. 情绪曲线
- 开头到结尾的情绪走向(共情 → 戳痛 → 给希望 → 赋能 → 升华 …)

### H. 结尾 & CTA
- CTA 类型:利他转发 / 关注 / 评论引导 / 收藏
- 升华方式

### I. 可迁移标注
- 这条的哪个套路能搬到「我的赛道」

## 样例 · 卡 #1 —「你可以熬夜,但这两个时辰请睡觉」

- **A 元信息**:aweme_id `7626585527169616354` | 健康养生 | 197s | 1128字 | 5.7字/s
- **B 钩子**:"你可以熬夜,但这两个时辰请睡觉" | 类型=让步式+反常识 | 公式=**让步**(你可以熬夜,不说教→不抵触)+**反常识承诺**(只要管住两个时辰)
- **C 痛点**:"头昏脑胀脸色差 / 越补越累"——描述体感,非讲道理
- **D 价值预告**:第 14s,"分享 2 个黄金睡眠时段 + 完整自救法,照着做就能把伤害降到最低"
- **E 骨架**:总分 | 2 时段 + 4 自救法,每点可执行 | 解法=**微调式**("实在没法早睡先睡 1-2 小时""每天提前 10 分钟")
- **F 可信度**:俗语背书"宁熬一整夜,莫误子时觉 / 老祖宗智慧" + 机制解释"消耗模式→修复模式" + 对比锚"比咖啡还提神"
- **G 情绪**:共情(不说教)→ 戳痛 → 给希望 → 赋能 → 温暖升华
- **H CTA**:利他转发"转发给身边熬夜的朋友" | 升华"身体是最宝贵的财富,好好爱自己"
- **I 可迁移**:钩子公式(让步+反常识)、价值预告、微调式解法、利他 CTA —— 四样几乎可无损搬到任何知识口播

## 样例 · 卡 #2 —「长期待在家里的人,到底是啥心态?」

- **A 元信息**:aweme_id `7621193793300454574` | 心理学 | 197s | 1461字 | 7.4字/s(更快,情绪密)
- **B 钩子**:"长期待在家里的人,到底是啥心态呢?" | 类型=身份点名+悬念提问 | 公式=**身份标签**(长期在家的人)+**悬念提问**(到底啥心态)
- **C 痛点**:第 2-11s 逐帧白描"刷手机到中午→下午睡→刷到凌晨两三点"——顶级"说的就是我"
- **D 价值预告**:⚠️ 无显式预告,改用**情绪悬念递进**("刚开始爽…可时间一长会变…")留人
- **E 骨架**:**递进式情绪揭示**(麻木→怕社交→自我否定→怀疑不值得被爱),非清单 | 解法仍是**微调式**("今天早起半小时""下楼走一圈")
- **F 可信度**:**重新定义痛点**("你以为是懒,其实是失去方向后的虚无")=给痛苦精准命名→被看见→信任
- **G 情绪**:几乎全程情绪——共情(挺爽)→层层戳痛(虚无)→重新定义(不怪你)→给希望→温柔托举
- **H CTA**:**双向利他**(对当事人"看见就是改变的开始"+对旁人"别催他,陪他") | 金句收尾"像影子,光一照就回来"
- **I 可迁移**:身份点名钩子、逐帧生活白描、重新定义痛点(给痛苦命名)、双向利他 CTA、金句收尾

## 已蒸馏的"母规律"(2 条样本,假设级,待更多样本夯实)

1. 长口播深度路线(~197s)
2. 前 3 秒独立成句 + 精准点名身份,逼观众对号入座
3. 痛点用体感白描,不讲道理
4. 解法是"微调式":不要你改变,只要你迈一小步
5. 利他式 CTA(转发给需要的人 / 提醒身边人),不求关注
6. 先共情、当自己人,绝不说教

> 差异:健康=干货清单型(收藏价值);心理=情绪共鸣型(转发价值)。
> 这 6 条 = 编剧 agent 的写作 rubric + 质检 agent 的打分清单的种子。

## 认知爆款骨架 v2(「自我重塑」认知类 5 条共用,样本:生产端57w/提问式赞美39w/不自证37w/点破恶意28w/谢谢不回26w)

四段式:
1. **冒犯式硬钩**:一句反常识断言 + 立刻指控观众("你以为X其实错了"/"你有个致命弱点")。先制造认知失衡,逼人看解答。
2. **机制命名**:给现象起个高级名字、讲底层逻辑(如别人质疑你="框架控制")→ "原来如此"的涨知识爽感。
3. **3-4 招可照搬台词**:每招=具体场景 + 逐字台词("遇到X就说Y")。落地型认知命门——不讲道理,给台词。
4. **金句收尾 + 赋能**:一句狠金句 +"你值得/你能更强"。

### 认知类 vs 健康/心理(别用错武器)
| 维度 | 健康/心理 | 认知 |
|---|---|---|
| 钩子 | 让步/共情软钩 | 冒犯硬钩(断言+指控) |
| 信任 | 俗语/机制 | 机制命名(起高级名词=显专业) |
| 方法 | 可执行步骤 | 可照搬逐字台词 |
| 情绪 | 被理解的温柔 | 反击/赋能的爽感 |

### 认知选题公式
**【目标人群的具体困境(社交/认知)】+【一句反常识解法断言】+【3-4 个可照搬台词/动作】**

母题按爆款度:① 社交反击/博弈(最爆,不自证37w/点破恶意28w/谢谢不回26w) ② 认知升维(生产端57w) ③ 社交好感(提问式赞美39w)。

> 抽象大道理不爆(纯"成长建议"仅3748赞),落地型(台词/反常识/硬核方法)才爆。
