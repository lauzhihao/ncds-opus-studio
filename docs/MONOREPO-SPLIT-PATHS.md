## 0. 统一改法（先建工具，再逐处替换）

三类脆弱路径，对应三种根治手段——**不要逐处 +1 改 `parents[N]`**：

1. **`parents[N]` 猜仓库根**（`parents[3]`→repo root、`parents[2]`→包根，迁进 `packages/<pkg>/src/<pkg>/` 后整体差一层）→ 建一个 **`repo_root()` helper**（向上找 `.git`/根 `pyproject.toml`），所有定位仓库根的地方统一用它，而非数目录层数。
2. **硬编码 `"src"/"ncds_opus_factory"/"templates"` 等 literal 段**（迁包后目录归属/包名都变）→ 包内资源（templates、tts_gen.py、pic_gen.py 等）改用 **`importlib.resources.files('<pkg>')`** 取，不再从仓库根重拼路径。
3. **运行时产物根 `state/`、`video-jobs/`**（多数已有 `NOF_STATE_DIR`/`NOF_VIDEO_JOBS_DIR`/`NOF_ARTIFACTS_ROOT` env 兜底）→ 运行时**一律以 env 为准**，import 期 default 仅作本地裸跑兜底；两 server 拆开后产物根**强制读 env、缺则 fail-fast**（见设计文档 §3）。
